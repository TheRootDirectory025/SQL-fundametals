# SQL Learning & Backend Database Practice

A practical SQL repository focused on backend development, database design, query writing, and performance optimization.

## Topics

- SQL Fundamentals
- Filtering and Sorting
- Aggregation
- Joins
- Subqueries
- Database Design
- Constraints
- Transactions
- CTEs
- Window Functions
- Indexes
- Query Optimization
- Backend Database Scenarios

## Database

PostgreSQL
